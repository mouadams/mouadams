## 🚀 Featured Projects

### 🟠 Orange Power AI — Telecom Energy Intelligence Platform

**Context:** Software Development Internship at Orange Maroc · 2026

A web platform for analyzing energy performance and power outages across telecom sites. It helps users monitor sites, analyze outage patterns, assess risk levels, and support battery-planning decisions.

**Key Features & Contributions**
- Developed web interfaces and backend API functionality for telecom-site data.
- Worked with outage data to support risk analysis and operational insights.
- Integrated Machine Learning workflows for risk prediction and battery recommendations.
- Supported data visualization for site, regional, and outage analysis.

**Tech Stack:** React, FastAPI, PostgreSQL, SQLAlchemy, Python, Scikit-learn, REST APIs.

### 🚌 AMANWAY — School Transport Tracking

**Context:** Freelance Project · 2026

A mobile application focused on school transport management and helping parents follow student journeys.

**Key Features**
- Parent-facing trip tracking and trip history.
- Real-time notifications for important journey events and changes.
- Backend services for application data and user workflows.

**Tech Stack:** React Native, Laravel, MySQL.

### 📄 e-Dépôt — Administrative Document Submission

**Context:** Mobile Development Internship at SNRT · 2025

A mobile application designed to simplify the electronic submission and tracking of administrative documents.

**Key Features**
- Mobile workflow for submitting administrative documents.
- Submission status tracking.
- Backend integration and persistent data storage.

**Tech Stack:** Flutter, Node.js, Express, MongoDB.

### 🌍 GO-MOROCCO — Tourism & Sports Information Platform

**Context:** Final-Year Project · 2025

A web platform created around the 2025 Africa Cup of Nations, bringing together sports and tourism information.

**Key Features**
- Centralized sports and tourism information.
- Interactive maps and multilingual content.
- Secure content management.

**Tech Stack:** Laravel, React.js, MySQL.

### 🎓 EduCenter — Backend Authentication Service

A backend project focused on building a structured authentication foundation for an education platform.

**Key Features**
- User registration and login.
- Email verification using OTP.
- JWT-based authentication.
- PostgreSQL persistence and API testing through Swagger and Postman.

**Tech Stack:** NestJS, PostgreSQL, JWT, SMTP Email, Swagger.

A workflow-oriented tool designed to automate procurement data preparation and export.

**Key Features**

**Tech Stack:** Python, Streamlit, SQLAlchemy, MySQL, Excel/CSV Processing, Gemini API.
